  c.email,
  c.full_name,
  COUNT(o.id) AS total_orders,
  SUM(o.total_eur) AS lifetime_revenue_eur
FROM customers c
JOIN orders o ON o.customer_id = c.id
WHERE o.status IN ('shipped', 'delivered')
GROUP BY c.id, c.email, c.full_name
ORDER BY lifetime_revenue_eur DESC
LIMIT 6;

Configuration & Security

OS Keyring Integration & Clean XDG Storage

Connection metadata and sensitive credentials are separated cleanly following Linux desktop standards.

D-Bus Secret Service Keyring

Database passwords and SSH passphrases are stored securely in your system keyring via the D-Bus Secret Service API (oo7), compatible out of the box with GNOME Keyring, KeePassXC, and KWallet.

XDG Bookmarks & 0600 Fallback

Non-sensitive connection profiles live in ~/.config/dbased/bookmarks.toml. In headless or minimal setups without a D-Bus Secret Service provider, DBased automatically falls back to ~/.config/dbased/.credentials.toml with strict 0600 permissions.

Lightweight Native Footprint

Compiled to a single native binary (~5 MB package size) with Wayland and X11 support via GTK4 and Libadwaita. Control runtime diagnostics anytime via RUST_LOG=dbased=debug.
